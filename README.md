# 🏥 SISTEMA WEB FULL-STACK PARA ATENDIMENTO PRÉ E PÓS-OPERATÓRIO

> **Projeto de Extensão**

---

## 📋 Sobre o Projeto
Este projeto consiste no desenvolvimento e implantação em ambiente de produção (Cloud) de um sistema web profissional voltado para uma enfermeira especialista em cuidados pré e pós-operatórios. 

O objetivo principal da aplicação é proporcionar uma presença digital humanizada, que transmita acolhimento e segurança desde o primeiro contato, otimizando a captação de pacientes e automatizando o fluxo de atendimento por meio de fichas cadastrais integradas diretamente ao WhatsApp e a uma base de dados relacional.

---

## ✨ Principais Funcionalidades
- **Apresentação Profissional:** Exibição da trajetória, especializações e autoridade da profissional na área da saúde.
- **Jornada de Cuidado:** Detalhamento claro dos serviços oferecidos e das etapas de acompanhamento do paciente.
- **Depoimentos Reais:** Seção dedicada à prova social e feedback de pacientes atendidos.
- **Formulário de Avaliação Inteligente:** Coleta estruturada de dados essenciais e complementares do paciente (com nível de dor, procedimento cirúrgico, hospital, etc.).
- **Integração com WhatsApp:** Envio automatizado dos dados preenchidos diretamente para o WhatsApp de atendimento da profissional com mensagens formatadas (`wa.me`).
- **Persistência de Dados:** Registo seguro de todas as solicitações em uma base de dados relacional em nuvem.

---

## 🛠️ Tecnologias e Arquitetura (Stack)
O projeto foi estruturado em uma arquitetura moderna de três camadas (*Full-Stack Cloud*):

* **Frontend:** 
  * [React](https://react.dev/) + [Vite](https://vitejs.dev/)
  * [Tailwind CSS](https://tailwindcss.com/) (Estilização responsiva e moderna)
  * Hospedagem: **Vercel**
* **Backend:** 
  * [Java](https://www.java.com/) + [Spring Boot](https://spring.io/projects/spring-boot) (API RESTful)
  * Hospedagem: **Render**
* **Banco de Dados:** 
  * [PostgreSQL](https://www.postgresql.org/) hospedado na **Neon.tech**
